# Outreach

Keep manuscript-connected outreach here: plain-language summaries, announcements,
press material, blog drafts, and their visuals. Add only the formats needed for
this project; publisher-specific requirements belong in the relevant draft.

## Organization

- Keep text drafts here; use a named subfolder for a self-contained article or
  website bundle when needed.
- Keep reusable figure generators and shared styles in `visuals/`, with assets
  in `visuals/images/` and expensive computed data in `visuals/cache/` when used.
- Keep generators and cache provenance available. Document reproduction commands,
  dependencies, parameters, and runtime; distinguish schematic illustrations from
  computed results. Read the project's figure guide for tooling and export rules.
- Preserve an editable master and export delivery formats separately. Check the
  actual web or print rendition for fonts, layout, and animation playback.

## Sources and delivery

Record the authoritative source and destination when copying material to a
website, press office, or another repository. Reconcile downstream edits back
into that source rather than allowing parallel drafts to drift.

For each delivered item, record the related manuscript version, external asset
credits/licenses, and delivery status. Check current venue requirements and any
applicable embargo before publication. Publishing or sending material requires
explicit author authorization; preparing a draft does not authorize delivery.

Keep the scientific scope consistent with the paper: explain what is new, label
theoretical predictions as predictions, and distinguish illustrations from data.
